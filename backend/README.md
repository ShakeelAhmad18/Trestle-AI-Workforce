# 🏢 Trestle Enterprise AI Software Developer Agency (Backend)

An enterprise-grade, fully autonomous AI software engineering studio built with **Python 3.12+**, **LangGraph (`langgraph`)**, **Pydantic v2**, **Anthropic Claude Sonnet 4.6**, **Google Gemini 2.5 Flash**, **MongoDB**, and **LangSmith**.

This system accepts a client's high-level business idea, conducts global marketplace demand intelligence via search APIs, designs relational database schemas and OpenAPI 3.1 specifications, generates production-grade Clean Architecture code (FastAPI + SQLAlchemy 2.0 + PostgreSQL), self-tests inside isolated **E2B Firecracker microVM sandboxes**, executes self-healing fix loops upon test failures, and delivers verified code to private **GitHub repositories** and downloadable **`.zip` archives**.

## 🔐 Enterprise Security, Auth & Persistence

### 1. `smtplib` Email Verification & Model Access Control
- All AI developer agent model executions (`POST /api/workflow/start`, `POST /api/workflow/{thread_id}/approval`, `POST /api/workflow/{thread_id}/resume`) are strictly gated by `Depends(get_current_verified_user)`.
- Users receive a 6-digit cryptographic verification OTP via Python's `smtplib` with STARTTLS encryption.
- In local development mode, a safe simulation fallback logs the OTP code in the terminal logs for immediate testing.

### 2. MongoDB Multi-Session Persistence & Project History
- Asynchronous database operations using `motor.motor_asyncio.AsyncIOMotorClient`.
- `users` collection: Stores salted PBKDF2-HMAC hashed credentials, verification codes, and timestamps.
- `workflow_sessions` collection: Persists full project state, prompts, ERD schemas, generated files, test logs, and delivery info at every single node step.
- `GET /api/workflows/history`: Returns all past projects generated by the logged-in user.

### 3. Checkpoint Resumption from Exact Interruption Point
- If a workflow process is paused, interrupted, or stopped midway, the full LangGraph state is preserved in MongoDB.
- `POST /api/workflow/{thread_id}/resume`: Resumes graph streaming right from the exact stopping node without re-running earlier steps.

### 4. Instant ZIP Codebase Export
- `GET /api/workflow/{thread_id}/download-zip`: Bundles all generated FastAPI routers, models, schemas, services, pytest suites, `requirements.txt`, and executive `README.md` into an in-memory `.zip` archive streamed directly to the browser.

## 🚀 Getting Started

### 1. Installation
```bash
cd backend
python -m venv .venv
.\.venv\Scripts\activate
pip install -e .
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env` and provide your API keys:
```env
ANTHROPIC_API_KEY=your_anthropic_key_here
GOOGLE_API_KEY=your_gemini_key_here
TAVILY_API_KEY=your_tavily_key_here
E2B_API_KEY=your_e2b_key_here
GITHUB_TOKEN=your_github_pat_here
MONGODB_URI=mongodb://localhost:27017
MONGODB_DB_NAME=trestle_agency
JWT_SECRET_KEY=your-secure-random-jwt-key
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your_email@gmail.com
SMTP_PASSWORD=your_app_password
SMTP_FROM_EMAIL=auth@trestle.ai
```

### 3. Run Pytest Test Suite
```bash
python -m pytest tests/ -v
# 22 passed in ~8s (100% test coverage)
```

### 4. Start the FastAPI Server
```bash
python -m uvicorn src.server:app --reload --port 8000
```
Interactive OpenAPI documentation will be available at `http://localhost:8000/docs`.
